# PetLife
Projeto de criação HTML/CSS de uma platraforma de petshop

Sobre o Projeto

Nosso projeto é um Pet Shop completo, criado para oferecer produtos e cuidados essenciais para cães e gatos. Trabalhamos com ração, petiscos, brinquedos, acessórios, produtos de higiene e itens para o bem-estar dos animais. Além da venda de produtos, o Pet Shop também busca oferecer serviços que ajudam nos cuidados dos pets, proporcionando qualidade, segurança e praticidade para os donos. O site foi desenvolvido para facilitar a navegação, permitindo que o cliente conheça nossos produtos e serviços, encontre o que precisa e entre em contato de forma rápida e simples. Nosso objetivo é criar um espaço moderno, organizado e confiável, onde os clientes possam encontrar tudo o que seus pets precisam em um só lugar.
